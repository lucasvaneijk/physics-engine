# 🚀 physics-engine 
I am making a physics engine as a fun project to learn more about python and just to have fun

# 📘how to use
## windows
To use this project you fist have to install customtkinter. 
To install customtkinter open powershell and paste this in there
make sure you have python installed

if you don't install it via the microsoft store

```bash
pip install customtkinter
```
then run
```bash
python physics_engine.py
```
